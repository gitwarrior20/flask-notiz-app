# 📝 Flask Notiz-App

Meine erste vollständige Webanwendung mit Python und Flask.

## 🚀 Funktionen

- 👤 Benutzerregistrierung & Login
- 📝 Notizen erstellen
- ✏️ Notizen bearbeiten
- 🗑️ Notizen löschen
- ♻️ Papierkorb mit Wiederherstellen
- 📌 Notizen anheften
- 🏷️ Kategorien
- 🔎 Suche & Filter
- 📊 Dashboard mit Statistiken
- 👤 Profilseite
- 🌙 Dark Mode

## 🛠️ Verwendete Technologien

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## 💻 Installation

Repository klonen:

```bash
git clone https://github.com/gitwarrior20/flask-notiz-app.git
```

Projekt öffnen:

```bash
cd flask-notiz-app
```

Virtuelle Umgebung erstellen:

```bash
python3 -m venv .venv
```

Virtuelle Umgebung aktivieren:

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

Abhängigkeiten installieren:

```bash
pip install -r requirements.txt
```

Anwendung starten:

```bash
python app.py
```

Danach im Browser öffnen:

```
http://127.0.0.1:5000
```

## 🎯 Projektziel

Dieses Projekt entstand, um den Umgang mit Flask, Datenbanken und Webentwicklung zu lernen. Dabei wurden Benutzerverwaltung, Datenbankabfragen, Templates und modernes Frontend-Design umgesetzt.
