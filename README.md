# 📝 Flask Notiz-App

Eine einfache Notiz-App gebaut mit Python und Flask.

## 🚀 Funktionen

- ✅ Notizen erstellen
- ✅ Notizen anzeigen
- ✅ Notizen bearbeiten
- ✅ Notizen löschen
- ✅ Speicherung mit SQLite
- ✅ Online bereitgestellt mit Render

## 🛠️ Technologien

- Python 3
- Flask
- SQLite
- HTML
- CSS
- Git & GitHub
